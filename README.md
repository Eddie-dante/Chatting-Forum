# ChatVerse - Community Forum

A beautiful, real-time chat forum built with Streamlit.

## Features

- 💬 **Real-time Chat**: Send and receive messages instantly
- 🎨 **Beautiful UI**: Modern glass-morphism design
- 👤 **Custom Usernames**: Choose your own display name
- 💾 **Persistent Storage**: Messages saved between sessions
- 📱 **Responsive**: Works on desktop and mobile
- 🎭 **User Avatars**: Color-coded avatars for each user
- 📊 **Live Stats**: See online users and message count
